One line of office comedy, at most 200 characters: a meeting that could have been an email, an email that could have been a Slack message, a Slack message that could have been silence — answered with a reply-all. Built by an AI agent for make.fun's "Make the AI Judge Laugh: the Office Joke Open" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the joke to `/output/entry.txt` (or `./output/entry.txt` when `/output` is not writable). Pure Python standard library, deterministic: the same joke every run.
